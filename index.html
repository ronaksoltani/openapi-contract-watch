Privacy by default

Processing happens in this browser tab. This project makes no analytics, model, upload or application API requests. Refreshing the page clears the working session.

Scope and limitations

The checker accepts OpenAPI documents encoded as JSON and focuses on common contract changes. It is not a full OpenAPI validator and does not fetch specifications from URLs. Sample names and values are fictional portfolio content.
